How to use FTCIntel

Getting Started

Sign Up Register your team number and contact email. You'll receive an access token by email.
Login Enter your team number and the token you received to access the dashboard.
Guest Mode After login you're in guest mode — you can view intel and data but cannot submit matches. Click CONNECT on the banner to enable scouting.

Scouting

Connect as Scout Click CONNECT, enter your Scout ID (provided by your team admin), and select the active event.
Recording a Match Fill in target team, match number, alliance position, and scoring counters (Auto Scored, Auto Missed, Teleop Points), then press SAVE MATCH.
Scout IDs Scout IDs must be registered by a team admin in the Admin Panel before they can be used.

Intel & Data

Intel Tab Search any team number to see average teleop score, last-3 average, max auto performance by alliance position, and a full match history chart.
Event Filter Filter results to the current event only, or search across all recorded events.
Data Tab View the raw scouting table for all matches submitted by your team.

Events

Switching Events Go to the Events tab, select a different event from the dropdown, and press SWITCH EVENT. The active event is used for intel filtering and match submission.

Admin Panel

Access Click Admin Panel in the sidebar and enter the admin password you received when registering.
Manage Scouts Add or remove Scout IDs that are authorized to submit match data for your team.
Edit Database Admins can edit or delete individual scouting records directly from the admin panel.
